PROJETO ESTRUTURAS DISCRETAS - GRAFOS (INF1631 - 3WB)

Requisitos: Python 3.8+ (apenas biblioteca padrao, sem instalar nada).

Executar o programa (use o p e a seed do seu grupo):
    python euler.py --p 0.30 --seed 137
Parametro opcional: --n 10 (numero de vertices, padrao 10)

Executar os testes obrigatorios (C4, P4, desconexo, vazio) e extras:
    python test_euler.py

Arquivos:
    euler.py       - programa e funcoes (gerar_grafo, graus, conexo, euleriano,
                     circuito_euler, valida_circuito)
    test_euler.py  - testes automatizados
